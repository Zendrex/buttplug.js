## Protocol Types

### OutputType

Output actuator type string literal union. All supported output types:

```ts
type OutputType =
  | "Vibrate"
  | "Rotate"
  | "RotateWithDirection"
  | "Oscillate"
  | "Constrict"
  | "Spray"
  | "Temperature"
  | "Led"
  | "Position"
  | "HwPositionWithDuration";
```

### InputType

Input sensor type string literal union. All supported input types:

```ts
type InputType =
  | "Battery"
  | "RSSI"
  | "Pressure"
  | "Button"
  | "Position";
```

### OutputCommand

Discriminated union of output command payloads, keyed by actuator type. Each variant is a single-key object:

```ts
type OutputCommand =
  | { Vibrate: { Value: number } }
  | { Rotate: { Value: number } }
  | { RotateWithDirection: { Value: number; Clockwise: boolean } }
  | { Oscillate: { Value: number } }
  | { Constrict: { Value: number } }
  | { Spray: { Value: number } }
  | { Temperature: { Value: number } }
  | { Led: { Value: number } }
  | { Position: { Value: number } }
  | { HwPositionWithDuration: { Position: number; Duration: number } };
```

## Logger

### Logger

Optional diagnostics for library internals (transport, message router, reconnect, device parsing). **Application behavior should not depend on log output**; use [client events](#clienteventmap) and typed errors instead.

The interface supports hierarchical prefixes via `child()`.

<AutoTypeTable path="../src/lib/logger.ts" name="Logger" />

Two built-in implementations are exported:

- `noopLogger`: default; discards all messages
- `consoleLogger`: writes to `console` with a `[buttplug]` prefix

```ts
import { ButtplugClient, consoleLogger } from "@zendrex/buttplug.js";

const client = new ButtplugClient("ws://localhost:12345", {
  verbose: true,
});

// Explicit logger:
new ButtplugClient("ws://localhost:12345", { logger: consoleLogger });
```

### resolveDiagnosticsLogger

```ts
import { resolveDiagnosticsLogger } from "@zendrex/buttplug.js";

const logger = resolveDiagnosticsLogger({
  verbose: import.meta.env.DEV,
});
// Pass `logger` into anything that accepts the package `Logger` type.
```

Uses the same resolution rules as **`ButtplugClient`**: explicit `logger` wins; otherwise `verbose: true` selects **`consoleLogger`**; otherwise **`noopLogger`**.

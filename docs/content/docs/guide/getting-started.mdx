Install the package, connect over WebSocket to [Intiface Central](https://intiface.com/central/), and send a vibration command. For browser-only setups without Intiface, see [WASM Transport](/docs/guide/wasm).

## Run Intiface Central

1. Download and open [Intiface Central](https://intiface.com/central/).
2. Enable **Start Server** (default WebSocket: `ws://127.0.0.1:12345`).
3. Leave Central running while your app connects.

<Callout type="info">
  `127.0.0.1` and `localhost` are equivalent for local development. Use whichever matches your Central settings.
</Callout>

## Connect and scan

<Steps>
  <Step>
    ### Create the client

    A URL string uses the built-in WebSocket transport:

    ```ts
    import { ButtplugClient } from "@zendrex/buttplug.js";

    const client = new ButtplugClient("ws://127.0.0.1:12345");
    ```
  </Step>

  <Step>
    ### Listen before connecting

    Register handlers before `connect()` so you do not miss early devices:

    ```ts
    client.on("device.added", async ({ data: { device } }) => {
      console.log(`Found: ${device.displayName ?? device.name}`);
    });
    ```
  </Step>

  <Step>
    ### Connect and scan

    ```ts
    await client.connect();
    await client.startScanning();
    ```

    `connect()` opens the socket and completes the v4 handshake. `startScanning()` asks the server to discover hardware; each match emits `device.added`.
  </Step>

  <Step>
    ### Send a command

    ```ts
    client.on("device.added", async ({ data: { device } }) => {
      if (device.canOutput("Vibrate")) {
        await device.vibrate(0.5);
        setTimeout(() => device.stop(), 2000);
      }
    });
    ```

    `0.5` is a normalized intensity in **0–1**. The library maps it to each feature's device range (so `0.5` is the midpoint of whatever range the server reports).
  </Step>
</Steps>

## Complete example

```ts
import { ButtplugClient } from "@zendrex/buttplug.js";

const client = new ButtplugClient("ws://127.0.0.1:12345");

client.on("device.added", async ({ data: { device } }) => {
  console.log(`Found: ${device.displayName ?? device.name}`);

  if (device.canOutput("Vibrate")) {
    await device.vibrate(0.5);
    setTimeout(() => device.stop(), 2000);
  }
});

client.on("connection.disconnected", ({ data: { reason } }) => {
  console.log("Disconnected:", reason ?? "unknown");
});

await client.connect();
await client.startScanning();
```

## What happens next

| Step | What you see |
| --- | --- |
| `connect()` | `connection.connecting` → `connection.connected` |
| `startScanning()` | `scan.started`, then `device.added` per device |
| Scan ends | `scan.finished` (or call `stopScanning()` yourself) |
| Power off / unplug | `device.removed` for that hardware |
| Quit Central or close socket | `connection.disconnected`; server stops all devices |

Devices stay in `client.devices` until `device.removed` or disconnect. `device.added` fires for every newly added device, including when a removed device rejoins.

title: Sensors
description: Read and subscribe to device inputs
---

Sensors on [`Device`](/docs/client/device) support **one-shot reads** and **push subscriptions**. Values are integers in each sensor's server-reported range.

```ts
if (device.canRead("Battery")) {
  const level = await device.readSensor("Battery");
  console.log(`Battery: ${level}%`);
}
```

## Sensor types

| Type | Typical use | Example values |
| --- | --- | --- |
| `Battery` | Charge level | `0`–`100` |
| `RSSI` | Bluetooth signal strength | Negative dBm |
| `Pressure` | Pressure sensor | Device-specific range |
| `Button` | Physical button | `0` released, `1` pressed |
| `Position` | Position sensor | Device-specific range |

Not every device exposes every type. Use `canRead` and `canSubscribe` before calling; the flags are independent per type.

## One-shot reads

`readSensor(type, index?)` sends an `InputCmd` with `Read`, waits for `InputReading`, and returns the numeric value.

```ts
const battery = await device.readSensor("Battery");

// Second pressure sensor on the device
const pressure = await device.readSensor("Pressure", 1);
```

Throws `DeviceError` if the sensor is missing or reads are unsupported.

## Subscriptions

`subscribeSensor(type, callback, index?)` registers for server-pushed readings. Returns an async **unsubscribe** function.

```ts
const unsubscribe = await device.subscribeSensor("Button", (value) => {
  console.log(value === 1 ? "pressed" : "released");
});

// Later
await unsubscribe();
```

You can also unsubscribe by type and index:

```ts
await device.unsubscribe("Button", 0);
```

If the server rejects the subscribe command, no local callback is registered.

## Client-wide input events

Every pushed reading also appears on the client:

```ts
client.on("input.reading", ({ data: { reading } }) => {
  console.log(`Device ${reading.DeviceIndex}`, reading.Reading);
});
```

Use device-level subscriptions when you only care about one device; use `input.reading` when one handler should process all hardware.

## Capability matrix

```ts
device.canRead("RSSI");       // one-shot read supported
device.canSubscribe("Pressure"); // streaming supported
```

A sensor can support read only, subscribe only, or both. Check the flags your UI needs.

## Cleanup

Subscriptions are cleared when:

- You call `unsubscribe` or the function returned from `subscribeSensor`
- The device is removed (`device.removed`)
- The client disconnects

After disconnect, create a new subscription when the device reappears on `device.added`.

---
title: Easing
description: 5 interpolation curves for smooth transitions between keyframe values.
---

```ts
{ value: 1, duration: 1000, easing: "easeInOut" }
```

Each keyframe can specify an `easing` curve that controls how values interpolate over the transition duration. The easing function maps normalized time (0-1) to an output value that blends between the previous keyframe's value and the current target.

## Curves

**linear:** Constant rate of change. Default when `easing` is omitted.

**easeIn:** Cubic acceleration (`t^3`). Starts slow, ends fast. Used by the `ramp_up` preset.

**easeOut:** Cubic deceleration (`1 - (1-t)^3`). Starts fast, ends slow. Used by `ramp_down`.

**easeInOut:** Cubic ease in and out. Used by the `wave` and `stroke` presets.

**step:** Holds the previous value until the duration ends, then snaps to the target (`t < 1 ? 0 : 1`). Useful for a delay before an instant change.

## Usage in Keyframes

Easing is optional on every `Keyframe`. When omitted, `linear` is used. Zero-duration keyframes ignore easing entirely since there is no transition to interpolate.

```ts
const keyframes = [
  { value: 0, duration: 0 },                       // instant start
  { value: 1, duration: 1000, easing: "easeIn" },  // accelerate up
  { value: 1, duration: 500 },                      // hold (linear)
  { value: 0, duration: 1000, easing: "easeOut" },  // decelerate down
];
```

You can mix curves on one track, for example `easeIn` on the attack and `easeOut` on the release, or `step` to hold a value before a snap.

## Runtime Access

The `EASING_FUNCTIONS` export provides direct access to each curve as a `(t: number) => number` function, keyed by name.

```ts
import { EASING_FUNCTIONS } from "@zendrex/buttplug.js/patterns";

const eased = EASING_FUNCTIONS.easeInOut(0.5); // 0.5
const stepped = EASING_FUNCTIONS.step(0.99);   // 0
```

All functions accept values in the 0-1 range and clamp out-of-bounds inputs. [`Easing` type](/docs/patterns/types#easing).

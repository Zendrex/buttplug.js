```ts
import { ButtplugClient } from "@zendrex/buttplug.js";
import { PatternEngine } from "@zendrex/buttplug.js/patterns";

const client = new ButtplugClient("ws://localhost:12345");
await client.connect();

const engine = new PatternEngine(client);
const id = await engine.play(device, "wave");

await engine.stop(id);
```

## Setup

Constructor takes a connected [`ButtplugClient`](/docs/client). `defaultTimeout` overrides the 30-minute safety auto-stop:

```ts
const engine = new PatternEngine(client, {
  defaultTimeout: 600_000, // 10-minute override
});
```

Subscribes to `connection.disconnected` and `device.removed`; matching patterns stop automatically. `engine.dispose()` removes engine subscriptions.

## play()

First argument: `Device` or device index.

**Preset name** ([built-in presets](/docs/patterns/presets)):

```ts
await engine.play(device, "pulse", { intensity: 0.7 });
```

**Custom tracks** ([keyframes](/docs/patterns/custom-tracks)):

```ts
await engine.play(device, tracks, { loop: true });
```

**PatternDescriptor** for data-driven descriptors (e.g. JSON).

Returns a pattern ID. A new `play()` on the same device stops any running pattern on that device first.

## Stop

- `stop(patternId)`
- `stopByDevice(deviceIndex)` (returns count)
- `stopAll()` (returns count)

## Lifecycle

Disconnect stops all patterns (`reason: "disconnect"`). Device removal stops patterns for that device (`"deviceRemoved"`). Safety timeout stops long runs (`"timeout"`).

<Callout type="warn">
  Default safety timeout is **30 minutes**. Override with `defaultTimeout` (engine) or `timeout` (per pattern). `timeout: 0` disables the limit.
</Callout>

`list()` returns `PatternInfo[]` (elapsed time, device index, descriptor).
